# About the model library
This folder contains publicly available DL models that can be downloaded by the user, saved in their local library and run.

# Adding a new model to the library 

Each model has a separate folder. The name of the folder serves as the ID of the model. 
The model must be Tensorflow.js compatible. If not, it can be converted using the following [utility](https://www.tensorflow.org/js/guide/conversion) provided by tensorflow. Save these files in a folder named "model"

In addition to the model files generated by the utility, add another file `info.json` to the folder.
This file will be used to generate the model library list and must contain the following details :


Once your folder is ready, add the folder here and create a Pull Request.
